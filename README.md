# LaChance_Place_Nav_2026
Code for LaChance place navigation study

Code and data for reproducing all data-based main figure plots for LaChance 2026 place navigation paper. Run generate_figures.py. Figure panels saved in 'LaChance_Place_Nav_2026/figures' directory. Requires Python 3.9+, matplotlib, seaborn, numpy, scipy, statsmodels, pandas, and built-in tools.
