# LaChance_Place_Nav_2026
Code for LaChance et al., Nature Communications, 2026

Code and data for reproducing all data-based main figure plots for LaChance 2026 place navigation paper. Run generate_figures.py, should take around 30 seconds. Figure panels saved in 'LaChance_Place_Nav_2026/figures' directory. Requires Python 3.9+, matplotlib, seaborn, numpy, scipy, statsmodels, pandas, and built-in tools.
